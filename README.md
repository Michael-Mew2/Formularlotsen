## 📌 Beschreibung
Das ist die neue Webseite der **Bremerhavener Formularlotsen**.  
Diese Webseite bietet den Besuchern die Möglichkeit sich über die Dienste der Formularlotsen zu informieren und stellt diesen zusätzliche Informationen in mehreren Sprachen zur Verfügung.

## 🚀 Features
- 📄 Verarbeitung von Kontaktanfragen
- 🌍 Mehrsprachig (8 Sprachen)
- 🏛 Bereitstellung von Informationsmaterialien
- 🔍 Verknüpfung mit weiteren Hilfsorganisationen

## 🛠 Technologien
- React
- React-Router
- SASS
- zustand

## 📦 Installation
```sh
git clone https://github.com/deinname/formularlotsen.git
cd formularlotsen
npm install
```
## 🏃‍♂️ Starten der Anwendung
```sh
npm run dev
```
