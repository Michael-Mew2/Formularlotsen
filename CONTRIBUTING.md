# 🤝 Mitwirken am Formularlotsen

## 🚀 Wie du beitragen kannst
1. Forke das Repository.
2. Erstelle einen Feature-Branch (`feature/neue-funktion`).
3. Commits sollten einem einheitlichen Format folgen:  
   ✅ `[🎨 feature]: Neue API-Endpunkte hinzugefügt`  
   ✅ `[🐛 bugfix]: Fehler in der Validierung behoben`
4. Pull Request stellen und auf Review warten.

## 📜 Code-Style
- JavaScript-Standard: ESLint (`npm run lint`)
- Dateistruktur nach MVC-Prinzip

## 💡 Wichtige Branches
- `main`: Stabile Produktionsversion  
- `dev`: Entwicklungszweig für neue Features  
- `feature/...`: Feature-spezifische Branches
