# 🔐 Sicherheitsrichtlinien

Falls du eine Schwachstelle findest, sende eine E-Mail an: **contact.michaels.website@gmail.com**

## 🚀 Sicherheitsmaßnahmen
- Verwendung von **JWT für Authentifizierung**
- Alle Benutzerdaten sind **verschlüsselt** (bcrypt, MongoDB)
- Regelmäßige **npm audit**-Prüfung auf Sicherheitsprobleme

## 🛠 Empfehlungen für Entwickler
